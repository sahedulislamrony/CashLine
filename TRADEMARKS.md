> Status: the name has not been cleared or registered as a trademark yet (see `docs/memory.md`, D-01). This policy states how the maintainer intends the name and logo to be used.

## You may

- say that your software is based on, derived from, or compatible with Cashline;
- use the name to refer to the official project in articles, reviews and documentation;
- build the app from source for your own use.

## You may not, without written permission

- publish a fork or modified build on an app store, website or package registry under the name "Cashline", a confusingly similar name, or with the Cashline logo or icon;
- use the name or logo in a way that suggests the maintainer endorses or is responsible for your build;
- use the application ID or bundle identifier of the official app.

## If you distribute a fork

Change the app name, icon, application ID and bundle identifier, and state clearly that it is not the official Cashline app.

Questions about this policy go to the maintainer through an issue.
